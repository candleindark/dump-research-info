# Acquisition inputs

This directory holds reproducible source snapshots used to generate candidate
research-information records. Snapshots are evidence, not hand-edited metadata
authority. Reviewed and validated records remain under `data/`.

For now the repository remains pure Git. Modest snapshots can be versioned
directly when their reproducibility value justifies it. Large or transient
snapshots can remain local as long as their source URL, version, and retrieval
command are recorded in the source README.
