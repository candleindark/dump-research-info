# Current CON site source

This directory records the versioned source used by the current
[Center for Open Neuroscience website](https://centerforopenneuroscience.org/).
The upstream source is
[`con/centerforopenneuroscience.org`](https://github.com/con/centerforopenneuroscience.org).

Files are generated by `scripts/con_site_ingest.py`:

- `snapshot.json` contains the exact upstream Git commit and source text needed
  to repeat an audit.
- `inventory.json` extracts page headings, text blocks, people, projects, links,
  images, engagement topics, and supporters.
- `coverage.json` compares person and project blocks with the current Things v2
  records and creates an agent/human review queue.
- `resolutions.json` records reviewed source-heading aliases to existing PIDs so
  that name variants are not mistaken for missing entities.

Refresh all three files with:

```sh
pixi run con-site-refresh
```

Rebuild the inventory and coverage report from the committed snapshot, without
network access, with:

```sh
pixi run con-site-audit
```

These reports are evidence and candidate inputs. They are not a second metadata
schema and are not consumed directly by the public site. Accepted information
must be mapped into the source-scoped JSON arrays under `data/` and pass the
same Things v2 validation as every other record.

Agent review should prioritize `missing_entity` items, then verify identifiers
and relationships before promotion. Missing text, links, and image references
may instead be editorial content or presentation assets; they should not be
forced into Things v2 fields that do not represent their meaning.
