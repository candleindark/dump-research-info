# Agent notes

These documents preserve the exploratory research and planning that preceded
the current implementation:

- `orinoco-con-website-plan.md`: initial component and deployment investigation.
- `con-research-information-architecture.md`: early end-to-end architecture
  plan.
- `con-metadata-model-gap.md`: proposed metadata model and content-gap analysis.
- `con-source-inventory-and-first-slice.md`: source inventory and proposed
  vertical slice.

The notes are intentionally retained because they contain source references,
alternatives, and questions that remain useful for later work. They are not
canonical specifications. Some early recommendations, including one-record
YAML authority and blanket media-review assumptions, were superseded by the
implemented Things v2 JSON workflow and subsequent owner decisions.

- `docs/references/site-delivery-and-editing.md`
